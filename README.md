# Diwali photo booth — photo page

Static page the photo booth's QR code opens: `https://craigmil.github.io/diwali/?p=<Google Drive file id>`.
Shows that guest's photo (from the booth's Drive folder, shared "anyone with the link"), a Save button,
and a link to the party album. Without a valid `p` it shows only the album link.
The booth side is `qr_result.py` (pibooth plugin on the Surface); notes in `~/Projects/todos/diwali.md`.
